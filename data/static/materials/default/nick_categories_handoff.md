# 昵称素材：交接

写给接手增改这批昵称的人（或模型）。**先读这一页，再按需要跳到四份正文**。
这一页只讲「现在是什么样、工具在哪、还欠什么」，不复述判据——判据在正文里，
免得两处各写一份、改一处忘一处。

## 一、这是什么，现在什么状态

`nick_categories.csv` 是一张 27 列的昵称素材表：每列是一个语义类，列里是若干条昵称素材，
供生成器随机取用。分类之间不是平级标签，是一条自顶向下、命中即停的判定链。

| | |
|-|-|
| 条目 | 1166 条（27 列，各列 11 至 121 条不等） |
| 形态 | 纯中文 835 / 混合 211 / 纯外文 120（含「造词与符号」整列 31 条） |
| 分支 | `nick-categories-polish`（最新提交见 `git log -1`） |
| 状态 | 判据、配比、符号池、验收四件事都已成文并落地；条目还会继续增补，但口径不再改 |

**口径在 11-25 至 11-26 两天里改过五轮。** 五轮都只动判定线，条目几乎没动——所以看历史数字前
先确认它是按哪一版数的，`changelog` 里每一节都标了当天的口径。

## 三、现行口径一页速查

### 3.1 形态：只问「去掉它，句意损不损失」

含汉字的前提下，**会损失**的才算混合，只有三种：

| 入口 | 例 |
|-|-|
| 句首、句中、句末的**成词**外文 | `记录赤壁Wind的周公瑾`、`Misty雨巷`、`亚历山大东征路上的Moon`、`情绪稳定Capybara` |
| 与数字或字母紧贴、构成一个值的符号 | `星轨偏航0.1°`、`+12dB`、`00:00`、`.zip`、`Alt+Tab`、`沸点100℃` |
| 颜文字 | `道理我都懂 ˘͈ᵕ˘͈` |

**不损失**的是尾注，条目仍算纯中文：句末单字母（`柏林墙倒塌那夜k` 的 `k`、`深渊观测者ξ` 的 `ξ`）、
句末数字（`码头候船室04`）、中段连接符（`白桃-乌龙` 的 `-`）、句末孤立符号（`风铃♫`）、
装饰连写（`澈正在输入中...`）。

两个最容易搞错的点：

- **句末外文看「是不是一个词」，不看位置。** 单字母是装饰，两个字母以上基本是词。缩写点算词内字符，
  `Q.E.D.`、`O.o` 各是一个记号。
- **形态与装饰是两笔账。** 一条纯中文挂 `✦` 仍是纯中文；形态由内容定，装饰只决定「这条带不带符号」。

### 3.2 配比：三组配平，其余不配

顺序是 **纯中文 : 句中数字 : 混合 : 纯外文**：

| 组 | 目标 | 现状 |
|-|-|-|
| 前三类（历史典故/演义、影剧、文学） | 85 : 5 : 10 : 0 | 104 / 6 / 12 / 0（共 122） |
| 后三类（游戏、其他虚拟角色、文娱） | 77 : 5 : 13 : 5 | 78 / 9 / 14 / 5（共 106） |
| 意象系列＋情感 | 72 : — : 23 : 5 | 72 / — / 23 / 5（199 / 63 / 13，共 275） |
| 城市空间～天文地理（七列） | 不配平 | 15.2% 混合（39 / 256） |
| 人名系列（人名、运营账号、事业） | 不配平 | 25.5% 混合（56 / 220） |
| meme / 网感 | 不配平 | 17.3% 混合（27 / 156） |

**意象系列＋情感的混合这一轮做完三步：先清，再补，再改形态。** 清是按「第二语义」摘掉 9 条纯翻译
（`Quartz白水晶`、`Islet屿`、`Xanthic浅黄蝶`、`沙丘与风纹_Dune`、`玻璃棱镜Prism`、
`海盐苏打水·Sea`、`雨夜Rain☂`、`晚安档案_Night`、`只对你心软Soft`），补是按低比例类写进 23 条
（意象组 19 条、前三类 2 条、后三类 2 条），改是把意象组那 19 条从「硬专名做实义」改成「半实义」。

现在 63 条混合 = 真外文 38 + 半实义 23 + 装饰 2，整组 72.4 / 22.9 / 4.7，对目标 72 : — : 23 : 5 是准的。

**外文承担多少信息，按列分工，不按一条尺子。** 前三类、后三类、人名系列可以写实义（专名、术语、
主谓宾成分）——`阿尔卑斯雪线挡住Hannibal`、`没画完那张地图的是Borges`、`垫底的治疗还抢DPS`，
外文是句子的真成分，摘了句子塌。意象六列、情感、七列、meme 只写半实义——中文先成句，外文在旁边
点一下，摘了句子仍成立：`月晕άλως套住整轮月`、`相纸polaroïd还没显影`、`红树mangue把根扎进咸水`。

判据因此不是「外文有没有复写」，而是**整条是不是一句话或一个场景**。`相纸polaroïd还没显影` 是句子，
半实义可以留；`玻璃棱镜Prism` 是两个名词并置的词条，仍是纯翻译，摘。**意象类宁可要回声，不要硬塞专名**：
`Orion腰带松了一颗` 像天文条目，`猎户的étoile腰带松了一颗` 才是这一列该有的分量。

**半实义 23/63 = 36.5%，不过半。** 这一格是回声不是对照表——整列都在复写，中文就成了外文的注释。
选词也不只用英语：法语 `étoile`、西语 `monzón`、德语 `föhn`、意语 `burrasca`、俄语 `тундра`、
葡语 `mangue`、希腊语 `άλως`、日语 `さくら`，跟着意象的出处走，比清一色英语更像真人写的。
读得出值的符号串也算半实义，例在七列：`推子推到+12dB`。

**混合目标定在初版的 2/3，是下限，不再下调。** 继续降只会逼着把成词的 `Moon`、`Capybara`
写成装饰。不配平的组，理由是形态由内容自带：物件本体天生具象中文，音乐/美术天生带术语外文，
按比例配只能改措辞。表头 `类/数字` 里的数字是生产配额，不是条数上限。

### 3.3 符号：按码位判，不按清单

可用 895 枚，判据是四步机械筛（折半全角、整组排除、认区、认类 `Sm`/`So`），
清单由 `materials_symbols_report.py` 生成，不手写。emoji 只挡默认彩色的一档，
单色可用（`☀ ☂ ☄ ❤ ♠ ♥ ☺ ⚙ ⚠`）。

位置配额是**抽取权重**，动手时抽，写完不回改：

| 位置 | 配额 | 现状 |
|-|-|-|
| 中间 | `_` 50 / 其他 ASCII 40 / 其他符号 10 | 65.1 / 27.0 / 7.9（分母 63） |
| 末尾 | `_` 12 / 其他 ASCII 10 / 字母 25 / 数字 8 / 其他符号 45 | 8.5 / 12.7 / 5.1 / 5.1 / 68.9（分母 119） |

`-` 已并入「其他 ASCII」，不再单列——单列的结果是每批都抽中它，几轮下来满屏横杠。

### 3.4 验收：带符号的条目占多少

与配比解耦、各算各的，落在区间即通过。区间按**现行分母**定（混合 211、纯中文 835），
不是从「一枚符号也能算混合」那版沿下来的旧数字（旧为 20%–40% / 10%–25%）：

| 形态 | 区间 | 现在 |
|-|-|-|
| 混合 | 15%–25% | 21.8%（46 / 211） |
| 纯中文 | 8%–15% | 17.0%（142 / 835） |

分组只复核不追点位，但超了出去要记下来。六个格子越界：七列混合 28.2%、七列纯中文 17.5%、
意象＋情感纯中文 19.6%、人名系列纯中文 15.8%、meme 纯中文 21.8%（上限外），
meme 混合 14.8%（下限外）；前三类混合 25.0% 正好压在上限上。前两个是两轮补符号（四列 15 枚、
验收 27 枚）加上来的，纯中文那几格是分母变小挤上去的——**符号一枚没动**，都按「不回头」不撤。

**先有语气，再挑符号。** 顺序是先判这一条该不该收住（话没说完、语气没落地），再去池子里抽；
没有这层关系的条目挂什么都只是贴纸。

## 四、开工流程

1. **选列**：看这一列现在多少条、缺什么形态。`materials_form_report.py --by-col`。
2. **判归属**：按 `nick_categories.md` 的判定链，命中即停；判不准先看「三组真正的易混」。
3. **写句**：判据在「写法」「精修：一台八级手术」。一条只做一件事，别叠两层修辞。
4. **定形态**：只有想补混合时才动外文或带值单位；补不了就承认这列该是中文的，别硬凑。
5. **补符号**（可选）：先在句子里找到语气落点，再 `tail_pick.py --slot end --kind 其他符号`
   抽 20 枚挑一枚。一批里能用的通常只有一两枚，抽的批次不够就再抽。
6. **记录**：改了什么写进 `changelog`（决策 + 数据），逐条写进 `chains`（原条目 → 现条目 → 理由）。
   只改错字、不改判据的，`changelog` 里一句话带过即可。

常用命令（在仓库根目录跑）：

```bash
python developer_tools/materials_form_report.py            # 分组形态 + 验收
python developer_tools/materials_form_report.py --by-col   # 逐列
python developer_tools/materials_form_report.py --check "亚历山大东征路上的Moon"
python developer_tools/materials_symbols_report.py --audit  # 越界字符与条目
python .temp/nick_repolish/tail_pick.py --slot end --kind 其他符号 --msg "句子的意思"
```

## 五、还欠什么（按优先级）

1. **11 条越界条目**，涉及的字符分三类：彩色 emoji 六种（`🍒`×2、`💕`×2、`🌊`、`🌙`、`🗝`、`💸`，
   整组不收）；颜文字零件四种（`˘`、`͈`、U+FE0F、U+FE0E，是组合符或修饰符，不算符号）；
   `℃` 一种（度量单位，语义正确但不是池内符号）。前两类该换成单色或删掉，`℃` 建议在文档里
   补一条度量例外的说明，别让审计每次都报同一条。`--audit` 可复现。
2. **形态这一步已收口，但写法分两档。** 三组都对上目标：前三类 9.8%、后三类 13.2%、意象＋情感 22.9%。
   做法是先按「第二语义」摘 9 条纯翻译，再按低比例类补 23 条，最后把意象组那 19 条从「硬专名」
   改成半实义。**实义（专名、术语、主谓宾）放在前六类和人名系列；意象六列、情感、七列、meme
   只做半实义（复写／近译／氛围词），整条必须成句，不做词条对照。** 判据是「整条是不是一句话」，
   不是「外文有没有复写」。半实义 23/63 = 36.5%，不过半；选词按意象出处分散到法、西、德、意、
   俄、葡、希腊、日语，不只英语。装饰剩 `εїз糖霜`、`吐泡河豚·oO`、`贴贴 ʚɞ` 三条，归符号层。
3. **六个格子超过验收区间**（七列混合 28.2%、七列纯中文 17.5%、意象＋情感纯中文 19.6%、
   人名系列纯中文 15.8%、meme 纯中文 21.8%，meme 混合 14.8% 低于下限）：全局 21.8% / 17.0%，
   混合在区间内，纯中文越了 2 个点。七列是两轮补符号叠出来的，纯中文那几格是分母变小挤上去的——
   **符号一枚没动**。都按「不回头」不撤；真要压下去得先逐条判钩子还在不在，不是按指标删符号。
4. **末尾字母只有 6 条**（目标 30）：字母后缀要求「像名字被截短」，硬贴就是凑数，宁可空着。
   这条是已知的、可接受的缺口。
5. **6 条括号收尾**（`魔女宅急便（扫把罢工）`、`空集（Null）`、`阿可（今日海拔更新中）` 等）
   不进尾饰统计：括号在判据里「只做一件事」，多数是合法括注，逐一判过再动，别整批删。
   另有 1 条叠字 `道理我都懂 ˘͈ᵕ˘͈` 不算合规尾饰，另案改。
6. **`tail_pick.py` 不在版本库**：要么挪进 `developer_tools/`，要么接受 `.temp/` 清掉后重写。
7. **`nick_categories_transposed.csv` 未跟踪**：是转置视图（列 → 行），供人工通读用，
   不是数据源。要么入库并说明，要么删掉，别让它一直挂在 `git status` 里。

## 六、纪律与坑

- **不回头重写。** 配额是抽取权重，不是审计指标。一批写完偏三五个点属正常，不为了对齐比例
  改已经立住的句子——那类改动通常只换了符号，内容一个字没动。
- **中文标点不是符号。** `，。、；：？！…—·‘’“”（）《》` 算中文，不推形态；当尾饰用时才记进
  修饰账的「其他符号」。`…` 不能拿来凑混合。
- **同一枚符号一列用两次以上**就从语气变成模板，换一枚。
- **别把外文统一挪到句首。** 位置不再改形态，但一律提到前面会变成格式。
- **判据改动要三处同步**：`forms.md`（现行规则）、`changelog.md`（决策与新数据）、
  `materials_form_report.py`（判定实现）。三处不一致时，以工具的输出为准——它是唯一可执行的判据。
- **本项目之外还有未提交改动**：`developer_tools/quip_draft_bench.py`（已修改）与本批无关；
  提交昵称工作时只 add `data/static/materials/default/` 下相关文件与 `developer_tools/materials_*.py`。
- **`.temp/` 不入库。** 里面还有旧版交接稿 `昵称取材工作交接.md`（28 列时代写的，已过时）、
  开工前快照、待分流池 `pool79.txt`。清 `.temp/` 之前确认没有只存在于那里的东西。
