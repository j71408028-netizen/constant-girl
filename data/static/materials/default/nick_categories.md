# 昵称素材判据：分类与写法

分类之间**不是平级标签**，而是一条自顶向下、命中即停的判定链：先问出处，再问具象，
最后才问意象与构词形式。往表里增删条目时按下面的顺序判，第一个命中的就是归属。

这份文件管两件事：一条条目**归哪一列**，一行字**怎么写才立得住**。
形态比例与符号用法在 `nick_categories_forms.md`，改动的来龙去脉在 `nick_categories_changelog.md`，
某一条被改过几次、原文是什么在 `nick_categories_chains.md`。

| 要找什么 | 去哪份 |
|-|-|
| 这条该进哪一列 | 本文「判定顺序」「两个合并类」「三组真正的易混」 |
| 这行字怎么写、怎么修 | 本文「写法」「精修：一台八级手术」「尾巴」 |
| 符号放哪个位置、形态怎么算、每列配多少 | `nick_categories_forms.md` |
| 哪个决定是哪天定的、为什么这么定 | `nick_categories_changelog.md` |
| 某一条被改过几次、原文长什么样 | `nick_categories_chains.md` |

本文只写**现行规则**。「哪天改的、改之前是多少」属于变更史，不放进来；
本文提到的「尾饰」「符号的位置判例」「造词与符号」「中英混搭」「三形态配比」，
都在 `nick_categories_forms.md`。

## 判定顺序

1. **有出处的角色 / 情节 / 舞台**：历史典故 → 影剧 → 文学 → 游戏；都不中才进「其他虚拟角色情节舞台」兜底。
2. **现实的人与身份**：文娱 / 人名（非直接引用）·短昵称 / 运营账号。
3. **可指认的现实具象**：城市空间、物件本体、**事业**、**现实日常**、野生动物/古生物、音乐/美术、
   天文地理/人类学与玄学、抽象概念、网络meme。
4. **情感**（她与「你」之间）：亲密、心动、等待、占有、离别、未说出口的态度。
5. **意象系列**（只剩一层氛围、无可指认对象时才进）：夜空 / 气象 / 其他自然 / 人格化动物与智能 / 器物 / 情绪。
   各子类按意象主体分：星月进夜空、风霜雨雪进气象、花木水势山海进其他自然、人格化的动物与智能进其专属列。
6. **构词形式兜底**（内容上无归属、靠外语感或生造感取胜）：自造意象短语 / 造词与符号 / 短小网感。

## 两个合并类

分类过细会让每一格都只剩「同一句式换个名词」，所以把六个强现实、尺度为零的旧类收窄成两个大格。
大格内部仍要按下面的范围判，不是随便往里塞。

### 事业（原 职场 + 职业场景 + 运动/竞争）

**只收「她曾经是、或仍在扮演的某种身份」，不收「办公室日常抱怨」。** 判据是这行字能不能读成
一个头衔、一处工作现场、一场比赛的余韵，而不是某个人下班后的碎碎念。

- 收：岗位直觉与职业权威（`物理课代表`、`移液枪吸头Tip`、`三脚架-定准点位`、`建筑系-通宵出图`）；
  工序与器具的熟练感（`阿珩剑山扎进枝`、`书画装裱刷浆糊～`、`许沐调酒器摇出分层`）；职场里的姿态与
  时间刻度（`小桉试岗期中途`、`凌晨的末班车`、`进度条-卡住`、`又在改需求`）；竞技的余韵
  （`阿禾穿上主场球衣`、`赛程进入最后一轮`、`主场球衣换季收起`）。
- 体育与竞技写**整体**，不写残片：写**运动服与场地**（`阿禾穿上主场球衣`、`主场球衣换季收起`、
  `泳池主场看台`）、**目标与赛程**（`宋柚的赛季目标达成`、`赛程进入最后一轮`、`目标中途搁置`）。
  「汗、秒表、积水的跑道、鞋印、翻到底的记分牌」这类要凑近才看得见的细部不再写，它们把一条
  身份压成了一个瞬间。也不写「运动员」「教练」这种泛称；头衔式约一成才用（`阿笙执哨全场`）。
- 不收：具体公司的工号、报销单号；纯情绪的「不想上班」（它属情绪，不属事业）；只写场所名而
  没有职业动作的（那是城市空间）。
- **旅行与研学在本列**（原「地理/旅行」拆分后并入）：收的是**因公在路上的现场**——换乘与改签、
  跨境验货、口岸与货场、带队研学、野外记录，落点是「谁在这条线上干什么」。这半边**必须带人名**
  才立得住：`阿泺改签-凌晨航班`、`阿筠带队-研学线`、`理货员阿沚数清箱`。不加名字就退回成
  旧列那种「旅行状态」（旧写法 `凌晨的候机厅`、`行李超重的那只箱子`），它与已拆掉的旧列同病
  ——谁都能用，谁都不像一个人。所以从旧列移过来的 19 条**全部落名**。
- 空泛的抱怨式短句（`绩效已读不回`、`甲方说再改改`）仍可留在本类，但它们**不是本类的示范**，
  新填时优先写有手艺感的。
- **情绪三分，不要整列都是抱怨**：消极 / 中性 / 积极大致各占三分之一。
  这一列与「瞬时观察及其反思」伴生：看见一个瞬间就替它下判断，最容易写成抱怨。写完先问它是
  **一句抱怨**还是**一处现场**：是抱怨就改成做成的一件事、积成的状态或再上场的动作——
  `红笔圈的那道题改三遍` → `红笔批过的题全对`，`跑道积水` → `目标中途搁置`。
  不是把「不好」硬写成「很好」，也不靠加形容词翻案。
- **这里可以落人名**，判据与运营账号相同（见「给这行字一个主人」「名字四分」）：名字是署名，
  不是主角；前置署名 / 后置附名 / 所属 / 全名四种写法混着用，不用冒号，不用括号当分隔，
  正文留 6~10 字。可以是固定名，也可以是占位符：`剪辑师Alice的加班日`、`修琴师绫音调好弦`、
  `会计{sur}{given}把账对平`。**含人名的条目约占一半略多**，且以固定名为主；与运营账号不同，
  事业**不套固定名与占位符各一半的配额**，三分之一是**下限**不是上限。
  名字仍是署名不是主角，不写成人物介绍。这一列与人名、运营账号同属**人名系列**，
  形态随署名走、不按配比表配平。

### 现实日常（原 消费与经济 + 美食与味觉 + 宠物与亲密关系）

**只收「一件具体的小物、一口具体的味道、一只具体的动物」，靠反差取胜。** 这一类的价值在于
巨大的存在却用一个最小的日常物命名；一旦写成了账目流水或购物清单，反差就散掉了。
配额 50 条，宁缺毋滥：宁可少几条，也不要用只剩甜味的词把格子填满。

- 收：一口具体味道（`锅底的焦糊味`、`半熟芝士的芯`、`咸豆浆-不放糖`、`螺蛳粉加双份酸笋`）；
  一只具体的家养动物与它的行为（`猫在我键盘上`、`它只认那个碗`、`给猫留的灯`、
  `喂了三年的流浪`）；一件小物的具体状态（若它本体胜过所属场景）。
- 不收：价格、分期、还款、满减这类**账目语言**（`分期还剩十一期`、`满三百减四十` 只作存量保留，
  不再新增）；品牌联名与购买凭证；把动物写成角色或身份的（那是「意象·人格化动物与智能」）。
- 也不收：**只有糖分没有具体物**的甜品调性（`半糖主义`、`暴击软糖`、`蛋糕味`），
  以及**只剩外语包装**的宠物名（`Cute小萌喵`、`Dog小Jump`、`Zebra的猫`）。它们读不出「一件什么」，
  只读出一层口味或一层可爱的滤镜，正是让这一列变得平庸的那部分。
- 现实日常与「物件本体」的分界：有生活场景与关系痕迹的进这里（`给猫留的灯`），
  单纯是「一个东西」的进物件本体（`旧收音机`）。

### 天文地理/人类学与玄学（原 地理/旅行 的地理半边 + 占星与玄学）

**两截共用一条判据：一个可指认的自然刻度，加一句人话。** 地理那截写地貌与天象
（`北回归线-起雾`、`峡湾尽头-灯塔`、`海平面-以下`、`稻田到地平`），玄学那截写历法、命理与
神话残片（`谷雨`、`霜降`、`子时生人`、`本命盘-第八宫`、`青丘有狐`）。两截都是「**具体的刻度 +
一层说法**」，不是抒情，也不是科普。

- 收：地貌、海陆、经纬、气候带、界碑与河口；节气与历法；星盘、签文、八字、择日；
  地方信仰与神话里能指认的那一件（`烛阴`、`麟踩过的土`）。
- 不收：**旅途与位移**（换乘、口岸、护照、候机厅——拆分后归事业，见上）；纯天气氛围
  （`雨停之前` 这类归意象·气象）；把地理讲成科普句（`北纬30度的成因`）；把玄学写成运势播报
  （`本周水逆注意`、`今日宜搬家`）。
- 这一列**不靠人名、也不靠头衔**，靠「一个刻度 + 一句人话」；加了署名反而像在写人，
  把这个刻度挤掉了。
- **以后不再新开「旅行」类**：旅途要么落成某个出差 / 研学 / 通勤的人的现场（事业），
  要么只是交通工具与天气（城市空间 / 意象·气象）。

### 情感（新增）

**指向她与「你」之间的关系位置，而不是一种说不清的氛围。** 判据是这句话里有没有隐含一个
「你」——有没有对象、有没有时间、有没有已经发生或即将发生的事。

- 收：未说出口的态度（`她从不先开口`、`假装不在乎的样子`、`偷偷喜欢很久了`）；
  时间与等待（`等一个不会来的人`、`想见你的第很多天`、`晚安是留给你的`）；
  体量带来的专属感（`只在你面前变小`、`为你留了半边天`、`低头是给你面子`）。
- 不收：没有对象的情绪质地（`虚妄`、`孤影`、`光影之隙的微凉` 属于「意象·情绪」）；
  梦境与幻想系列（`梦X` 式仍归「意象·情绪」）；纯告白口号。
- 与「宠物与亲密关系」的分界：那条写的是**动物**与「我」的相处，这条写的是**她**与「你」的关系。

## 三组真正的易混

### 动物三分：现实日常 / 野生动物与古生物 / 意象·人格化动物与智能

三条各管一件不同的事，不要按"猫 vs 鸟"这种物种来分：

- **现实日常**（原「宠物与亲密关系」）：和"我"有相处关系的家养动物，落点是陪伴与日常（猫在我键盘上、它只认那个碗、
  喂了三年的流浪、它只认那个碗）。判据是**有没有亲密关系**，不是物种。
- **野生动物与古生物**：指认到物种本身，写实或古生物（丹顶鹤、中华穿山甲、三叶虫、剑齿虎）。
  判据是**能不能报出物种名**，不带"我"。
- **意象·人格化动物与智能**：动物或智能体被赋予人格、身份、情绪，当成角色写（狂三の黑猫执事、
  博览群书の猫、数据迷途猫、肥宅快乐鱼、摸鱼仙人）。判据是**它像不像一个"谁"**，而不只是一只动物。

速判：写"我的猫"→现实日常；写"一只猫"→野生动物（若能报物种）否则意象；写"猫执事 / 猫卷王"→人格化。

### 名字四分：角色系列 / 人名 / 运营账号 / 外文

这四组都长得像名字，按**名字背后站的是谁**分：

- **角色系列**（历史典故 / 影剧 / 文学 / 游戏 / 其他虚拟角色情节舞台）：名字背后是一个**有出处的角色**，
  能追到哪部作品、哪段典故就进哪一列（兰亭序、哥谭阿卡姆雨夜、三体人脱水浸泡、艾尔登环）。
- **人名（非直接引用）/短昵称**：像人名，但**不指向具体角色**，只是个称呼（Ahri、Akira、Amy、知夏）。
- **运营账号**：名字背后是一个**账号身份 / 运营口吻**，重点在"这是个号"，不在"这是个人"。
  这个号是**她本人在经营**，为的是跟人说话——打招呼、求关注、解释自己、或者干脆嘲讽下面的人。
  所以主流是**亲切**，不是公文。像一个体量极大的普通网友在发帖：随性、翘尾巴、爱看热闹，
  偶尔阴阳怪气，也可以是一个只发天气、只在自己睡着时更新的个人号。

  **大部分条目要落到具体的人名上**（账号得有个主人）。落名有四种写法，
  混着用，不能满列都是 `{given}的X`：

  - 占位所属：`{given}的影子播报台`、`{given}的日常发疯记录`、`{given}的观测报告第很多期`
  - 前置署名：`{given}今天不营业`、`{given}只发天气`、`{given}还在头顶`
  - 后置附名：`快乐水质检员{given}`、`屋顶承重员{given}`、`身高争议方{given}`
  - 全名：`{sur}{given}的影子播报台`

  **不用冒号；括号不拿来当分隔。** 冒号在昵称里少见，显示端未必吃得住；括号只装可省略的内容
  （`{sur}可（还在长）`），拿它分隔署名或装一句实话，会让整列读起来像文件名的括注。
  需要断句就用 `_`：`公告_本月{given}不再变小`、`树洞投稿已满_{given}`。
  存量里的 `（{sur}氏）`、`（{given}）` 要改成 `_{sur}氏` 或并进句子。

  **长度按正文算，不按署名算。** 落名占 2~3 个字，正文留 6~10 字；这一列的上限是 18 字
  （含占位符原样计），超过就像简介不像昵称。

  `{given}` 是名、`{sur}` 是姓，程序按本轮掷出的姓名渲染；`阿楠`、`小满`、`Mika` 这类是写死的昵称或化名，
  **两种各占一半**（见第 5 级）。固定名不指向具体作品角色或在世真人，同一个名字不重复用。
  占位符那半边**姓与名都要配**：只堆 `{given}` 会让整列像同一批昵称换了个字，大约三到四成落 `{sur}`，
  其中一部分用全名 `{sur}{given}`。名字在这里不是主角，是**账号的署名**——
  所以不要把句式写成人物介绍。

  姓的写法偏向署名与认证，不偏向所属（`{sur}的影子播报台` 读着别扭，`{sur}{given}的影子播报台` 才顺）。

  - 亲切：`{given}今天不营业`、`有事请在我脚边留言`、`本账户由{given}本人运营`、
    `私信仅接收仰望{given}的申请`、`{given}只发天气`。
  - 嘲讽：`低头是{given}给你面子`、`转发前请确认楼高_{sur}氏`、`此处有巨大不明生物_{sur}氏`、
    `{given}只是路过`、`{given}雨天别@她`。
  - 无名的一小撮留给纯系统文案与纯氛围句：`该账号已停止运营`、`系统通知_该用户已睡着`、
    `账号异常稍后再试`、`内容已被屋顶挡下`、`本条发自云层之上`。`区域沉降预警中心`、
    `城市结构安全评估号` 这类机构腔只作存量保留，不再新增。
  - 不收：真实公司名称、具体工号、地推二维码式广告（`合作请邮件`、`广告位常年招租` 属存量）。
- **造词与符号**：名字背后**没有身份，只有字面**——靠小语种或字形取胜（`neko`、`sᴀɪʟ`、
  `Qlassy`）。判据是**去掉中文语境后是否还能读出人物或身份**；能，就回上面三列。

**名字落进事业列时仍按事业判归属**：它写的是岗位、现场或赛事，不是「人名」也不是「运营账号」列，
只是这行字有了主人。落名沿用上面那一整套（四种写法、不用冒号、括号不当分隔、姓名配齐、
正文 6~10 字），但不要求整列都落，也不写成账号口吻：`剪辑师Alice的加班日`、
`修琴师绫音调好弦`、`会计{sur}{given}把账对平`。

**中文固定名里另外三种写法**（人名 / 运营账号 / 事业通用，**合计不写满三成**，现为 7/100）：

| 写法 | 判据 | 例 |
|-|-|-|
| 改写音译式 | 标准音译名换掉一个字，换的是个人气，不是错字或搞笑谐音 | `奥黛丽` → `奥黛梨`、`薇薇安` → `薇薇岚` |
| 日式名 | 姓＋名的称呼，**不指向具体作品角色**；已有的假名单字（`Haru`、`Yuki`）不再加 | `白川澪`、`院长千夏`、`修琴师绫音调好弦` |
| 四字硬凑式 | 自己取姓＋三字名，连读要顺；「小X」别堆成模板；进账号时放后半段 | `温小雪梨`、`停工报告_沈小梨涡` |

这三种只改署名，不改归属：人名列仍按「只是称呼」判，运营账号仍按账号口吻判，事业仍按岗位现场判。
它们都占中文固定名名额，不额外增加配额。

速判：`哥谭阿卡姆雨夜` 有出处 → 角色系列；`Akira` 只是称呼 → 人名；
`收到请仰望` 是个号在说话 → 运营账号；`sᴀɪʟ` 只剩字形 → 造词与符号；
`剪辑师Alice的加班日` 有岗位和现场 → 事业（落了名也不改归属）。

**人名系列**：**人名（非直接引用）/短昵称、运营账号、事业**三列合称人名系列。它们都靠「有没有主人、
主人叫什么」立身，形态是署名方式的副产品，**不参与三形态配平**（见 `nick_categories_forms.md`
「三形态配比」）。事业不在上面这四分里——它按岗位与现场判归属，只是恰好要落名——但落名写法与
这两列共用。

### 拟人二分：娘化 / 意象·人格化动物与智能

两者都是"非人对象被写成人"，但一个锚在作品与社区上，一个只有气质：

- **娘化**（进「其他虚拟角色情节舞台」）：舰船、枪械、品牌、平台这类非人对象被造成了**有名字、有立绘、
  有出处的角色**（舰内拟人报、战术人形、NikeChan）。判据是**能说出它属于哪个作品、品牌或社区**。
- **意象·人格化动物与智能**：没有出处，也**与任何社区无关**，只剩一层模糊的气质（暴走猫、数据迷途猫、
  博览群书の猫）。判据是**说不出它出自哪里**。

速判：能追到舰C、少女前线、某个品牌或同人圈 → 娘化；追不到、只是一种味道 → 意象·人格化。
另外，娘化写的是角色，纯写物件本身的归「物件本体」。

## 两条要紧的原则

- **内容先于形式**：写成外文或混搭短语不改变归属。`桜色の風·キミとゆく` 进「意象·气象」，
  不进「自造意象短语」。
- **具体先于意象**：能指认到具体对象的，不进意象系列。

## 写法：头衔，以及头衔上的专名

这一节记的是**写昵称时的手上动作**，不分分类，全表通用。分类决定她「是谁」，这一节决定这行字
「怎么长成」。前者容易做全，后者才是体感平庸的根源：分类再细，每格都按语义填，最后都会滑向
「名词＋的＋名词」这一种句式。

### 主推句式：在词上加头衔

**不要写完整叙述，只给一个身份。** 头衔是职位、归属、状态、工序位置，落在名词或动作**之前**，
读起来是「一个不构成句子的称谓」。

- 好的：`半开麦检验员`、`爱豆营业监督员`、`圣巢虫卵编目员`、`交界地赐福看护`、`日音冷门曲库整理人`。
- **头衔是广义的**：不必凑出一个正式的职务名。`街机厅投币续命少女`、`罗马元老院的匕首`
  都是从头衔句法长出来的——一个带处所的身份、一个带所有格的身份，读起来同样「某个东西挂在身上」。
  判据不是「像不像职位」，而是**读者能不能一眼认出她在哪个位置上**。
- 要避免的：主谓宾齐备的短句（`他昨天来过这里`），以及把一个完整事件压进一行的写法
  （`零点前南瓜车掉头`、`追风筝时踩碎了云`）——偶尔可以留，但不要成片。

头衔用**完整中文**，不加 `·`、`°` 之类的装饰分隔符（`街机厅·投币续命少女` 的 `·` 一删就成立，
不必连句子一起换）。装饰分隔符留给本来就靠字形取胜的条目（外文、编号、emoji），不要拿它来做节奏。
**`-` 和 `_` 不在此列**：它们是断句与署名符号，不是装饰，允许更多使用（见「符号的位置判例」），
不必按「删装饰」处理；正文列里现有的符号大多是零星的、可删的。
**要的不是唯美与韵律**，是「一个职务挂在身上」的干脆。

### 自造意象短语：这一列不吃上面的规矩

这是全表**唯一按「构词」而不是按「内容」收条的一列**（判定链第 6 条）。它管的是
「没有可指认的出处、也没有可以报出来的物种或地点，靠**字本身的样子**立住」的那批条目。
所以正文列为了通顺而立的几条规矩，到了这里多数不适用：

| 正文列的规矩 | 在这一列 |
|-|-|
| 短句要补齐成一处现场 / 一个动作 | **不必**。一到三字就是它的正常体长 |
| 不用非标准字符 | **可以用**。`_`、`∅`、`∫`、`の`、`ฅ^•ﻌ•^ฅ` 这类是字形的一部分 |
| 通顺优先于字形 | **倒过来**。读不太顺但看得出字形，比通顺但普通更值钱 |
| 孤字要补一个落点 | 只有**纯汉字孤字**需要；靠符号认脸的不补 |

**收**：短词与孤字（`烬`、`弭`、`溟`、`魇影`、`银羽`、`零渡`）、生造词与生造组合
（`磷桦妪冰栊冽`、`森罗万象之外`）、外语与中文混拼（`Luna'sデイ`、`作業の案内者`、
`Kawaii即战力`）、符号即字形（`零∅`、`∫知逝の春解`、`__亡骸__`、`🗝️谜`）、
以及**语法上站不住、但读着有东西**的写法（`缤直往下掉`、`大心家的人早已回家`）。

**「错误语法」放开到什么程度**——这是这一列最难划的线。放开的是**句法**，不是**可读性**：

| 可以留 | 例 | 为什么成立 |
|-|-|-|
| 词性错位 | `脉冲到无极`、`缤直往下掉` | 读者看得出这是什么，只是不该这么搭 |
| 缺主语 / 缺谓语 | `三样都想要`、`百夜亮着` | 省略本身是语气 |
| 生造词 | `磷桦妪冰栊冽`、`甜心酱` | 字的质地就是内容 |
| 外语语法痕迹 | `Luna'sデイ`、`作業の案内者` | 外来感就是它要的东西 |

**不能留**：读不出指向的（把三个毫不相干的名词并排，谁都不修饰谁，删掉任何一个都不影响），
以及**占了别人的位置却不属于那一列**的（能报出物种的进野生动物，能指认地点与地貌的进天文地理，
真实存在的作品角色进影剧 / 文学 / 游戏——**内容先于形式**，写成生造短语也一样）。

**两条硬规则的例外**：这一列同样不用阿拉伯数字与「了」，但——数字若本身是字形
（`零∅`、`-1`），「了」若只是语气的收尾（`Fantasy泡泡破了`），按语法放开处理，不强制清。
**唯一不能破的是占位符**：`{sur}` / `{given}` 必须完整出现，中间的字符也不能切断它。

**判据只有一条**：把这条念出来，能不能听出**一个人给自己起的名字**，
而不是一句没写完的作文。这一列**不要为了通顺去补落点**——补了就是往正文列靠，
它本来的价值在字形与生造感上。

**但放宽不等于整列都写成孤字。** 孤字是这一列最锋利的形态，用多了就钝：
**连着的两行不要都只挂一个字**（读者翻下来只会觉得两格漏填了），
整列孤字控制在**一成半以内**（72 条里 11 条是上限，现在正好 11 条）。
超过这个密度，挑字形最弱的几条补成两到四字；**不是补成句子**，是补成词。

### 头衔上再加专名：约一半

头衔式里，**约一半要带上人名或地名**，让头衔有归属：是谁在担任、在何处担任。
这一半内部再分三种形态，**三种都要有**，不能全写成同一种收尾：

| 形态 | 样子 | 例 |
|-|-|-|
| 正序 | 头衔＋专名 | `阿卡姆夜班守卫`、`璃月元宵灯官`、`日音冷门曲库整理人` |
| 倒装 | 专名＋全角逗号＋头衔 | `梦露，替身第一位`、`绫波零，同步率观察员`、`郑和，第八次随行` |
| 「的」字 | 修饰语＋的（＋专名） | `记录赤壁风向的周公瑾`、`教坊司在册的后庭花`、`时间简史第七页看守` |

- 倒装用**中文全角逗号**，不用 `·`，也不写英文逗号；读起来像名单上的破折号注脚。
  逗号在这里分的是「谁」和「是什么职位」，不是两个并列项，所以不换顿号（详见「逗号还是顿号」）。
- 「的」字形态里，头衔可以整个省略，只留「谁在做什么」：`庞贝灰烬数到第五层的`、
  `三顾茅庐那天值门的`。收尾落在「的」上是与纯名词收尾差别最大的一种，各列都该有几条。
- **不要为倒装而倒装**：`帝国拯救者凯撒` 是自然成立的前置定语，`凯撒，帝国拯救者` 是名单写法，
  两者都对；但把动作硬拆成前置定语（`真迹看管兰亭序`）就不通了。

### 戏谑靠名不副实

戏谑感来自**称谓与事实对不上**，不需要另立语法规则：称作看守的其实在通风报信，
称作保管人的其实从没打开过。写法上仍是干净的头衔，只是她配不上这个头衔。

- 好：`长信宫灯熄灯人`、`维也纳森林伐木人`、`罗塞塔石碑误读者`、`元祐党人榜末位`、
  `爱豆营业监督员`、`偶像失格观察员`。

### 其余条目用四种变形

不写成头衔的那一半，按四种动作改造，目的都是**离开原句的句法**，不是把句子改得更漂亮：

- **抽字**：只留最有识别度的一两个字或词组，砍掉主谓结构（`赤壁借东风`、`大明宫词旧梦`）。
- **加冗余**：多叠一层同义或错位的词，让意思钝一点（`霸王别姬夜未央`、`旧时王谢堂前燕飞`）。
- **插入符号**：`°`、`_`、`~`、`⋆`、`✦`，制造「这不像人手写」的质感。
  注意这与「精修：一台八级手术」第 1 条方向相反：符号要么用在**靠字形取胜**的条目上（外文、编号、
  纯装饰性的短条），要么就别用。给一条本来就有实物的昵称加 emoji，是把它推回平庸。
  书名号只在**引用一件具体的作品**时用（`「肖邦」翻页`），不当装饰。
  圆括号不在这张符号表里：它是全表唯一用法被限死的符号，只装可省略的内容，见下一节。
  **别的符号没有被禁**，只是多数时候没活干——判断它是文书还是语气，见「尾饰」一节。

另有三种不该被「规范化」推平的存量：

- **稀有结构保护**：`金发笨蛋&战术人形` 的 `&` 在全表只有这一处，两个身份并列、谁也不修饰谁，
  `&` 正是这个关系的写法。换成一句话叙述（`战术人形不会迷路`）就把并列改成了单方陈述，
  结构消失、复杂度也没了。孤例本身有价值，别为了统一把它也收掉。同类还有 `机械#∞幽灵`
  的 `#∞`——夹在两个词中间、左右对称，也是全表孤例。
- **双关**：`Qing心灵语` 是「倾心」的谐音＋「心灵语」的字面，删掉拼音就只剩半句比喻（`清一色的心语`）。
  这类条目读的是**两个字面同时在场**，改写成通顺的散文就等于拆掉其中一层。
  `熵增∞` 归同一条：`∞` 既是装饰符号又是数学符号，「熵增到无穷」和「给熵增挂个无穷」同时成立。

### 括号只做一件事：装可省略的内容

圆括号是中文里的**可省略成分标记**。它只有一个判据：**括号连内容整块删掉，剩下的还是一句通顺的话，
而且不被误解。** 删掉以后不成立、或者从一句话变成了残句，就不该用括号。

- 可以：`艾可（出差失眠版）`、`充电线（打结版）`、`创可贴（未拆封）`、`魔女宅急便（扫把检修中）`、
  `{sur}可（身高每日更新）`——括号里是版本或状态，整块删掉以后，前半句仍是这个人在发帖。
- 不可以：`{sur}可（在群里潜水）`、`树洞投稿箱（已满）`——删掉后意思变了或丢了，
  说明括号里是正文而不是注释，要把它写进句子。
- 边缘但可留：`空集（Null）`——括号里是同一个词的另一种写法，属于可省略的等价注释，存量保留。

**括号不是分隔符。** 中文里想在视觉上分开两段，用 `·`、`_`、`-`：
`{given}的日常发疯记录` 不要写成 `{given}（发疯记录）`，`{given}发疯记录_{sur}` 也不要写成括注。

**括号不管强调。** 中文的圆括号没有强调功能；想点出某个词，靠换词、换句法，或者成对的装饰符号
（`°这°`、`~这~`、`*这*`——必须成对）。`不相信这（奇迹）` 这样把词单独括起来、指望它变重，是自创用法，
括号没有这个能力，要嘛改句子（`就是不相信这奇迹`），要嘛删掉括号。

**但括号里多一个限定词是可省略的正常用法，别混进上一条。** `不相信（这）奇迹` 和 `不相信这（奇迹）`
只差一个字的落点，前者成立、后者不成立：

- `不相信（这）奇迹`：删掉括号读作「不相信任何奇迹」，是这个人现在的整个态度；带上「这」，
  态度收到一件具体的事上——她本来等过一个东西，落空了。**括号在这里装的是「让句子变具体的那一点」，
  删掉仍然通顺、只是意思从具体退回笼统**，正是可省略。
- `不相信这（奇迹）`：括号里是中心词本身，删掉就剩「不相信这」，不成话。

判据还是同一句：**整块删掉，剩的还通顺吗？** 通顺、只是从「具体」退回「笼统」，括号就合法；
反过来，括号里装的是句子的主干，删掉就残——那不是强调问题，是括号用错了位置。

**注意别把这条放宽成「宾语也能括」**：`跳崖前先开（滑翔翼）` 的删法读作「先开」，
动词悬着没落地，严格按判据**不可省略**；它靠的是原文语气放松、读者不会往「开什么」上想，
属于存量容忍，不是范例，别照着写。

**不用括号的四种情况**：

| 想做的事 | 别写 | 写成 |
|-|-|-|
| 视觉分隔两段 | `{given}（发疯记录）` | `{given}的日常发疯记录`、`发疯记录_{given}` |
| 署名 | `此处有巨大不明生物（{sur}氏）` | `此处有巨大不明生物_{sur}氏` |
| 补一句括号外的事实 | `{sur}可（在群里潜水）` | `{sur}可只在群里潜水`（并进句子） |
| 给整条贴标题 | `树洞投稿箱（已满）` | `树洞投稿已满_{given}` |

`深夜emo回收站（{sur}）` 这种纯署名括注属于上表第二行，要改。

**注意别把可省略的括号当分隔删掉**：`{sur}可（身高每天都在更新）`、`{sur}遥（一步顶你一周）`
括号里说的是「她此刻长到哪儿了」，删掉整块仍然成立，属于可省略，只要减字（`{sur}可（身高每日更新）`），
不要并进句子、也不要换成 `_`。

括号里的减字，**照着现实里运营号真会用的写法减**：`身高每日更新` 是简介栏里常见的短句——
短、像状态说明、不说破。改写成 `还在长` 虽然更短，却从「运营口吻」变成了「自述口吻」，
而这一条的主体本来就是一个账号。**同类改写先问一句：这个说法在真实主页上会不会出现？**
会，就比更文学的说法更对。

**emoji 只剩黑白那一档可用**（判据与码位见 `nick_categories_forms.md`「符号池」）：默认彩色的一律不收，
单色的 `☀ ☂ ☄ ❤ ♠ ♥` 可以，但不写变体选择符。也不必给已有实物的条目加。

**同一列同一个后缀重复出现，就是模板。** 清理 `人名` 列时发现过五条
`Felix🐱`、`Hazel🌸`、`Aimee🍒`、`Arwen🌙`、`Kura_🌙`——五个条目、五种动物与花，但结构完全一样：
**一个外文名 + 一个无关的 emoji**。单看任何一条都无害，连着看却是同一张模板刷了五遍，
读起来像没填完的占位。判据不在 emoji 本身，在**「这个词尾换成人名后会重复多少遍」**：
重复，就说明它不是这条的字形，是格式。

**「数字」与「序号」不是一回事。** `三圈`、`第三圈`、`一层`、`一根弦` 是量词，属于那件东西的形状；
`第三位`、`第五层`、`第七页`、`707号`、`三层` 是从外面数上去的刻度。判据是能不能换成「那一个」：
`胶带缠到第三圈`、`包到第五层` 换成「那一圈」「那一层」就不成立——这类数字留着（属于例外）；
`梦露，替身第一位` 换成「那位替身」照样成立，说明它只是排位，该删。

**书名号只引作品。** `「肖邦」翻页` 的引号之所以成立，是因为它引的是肖邦那首曲子；不引具体作品时，
书名号是装饰，与括号一样不该进昵称。

第四种变形是**翻译半句**：把半句译成外文或音译，留一半中文（`機械仕掛けのエリス`、`樱木花道no回头`）。
外文在这里不是装饰，是让半句话离开原句的语法，所以它和前面三种一样，改的是句法不是文采。

### 逗号还是顿号

全表有 23 条昵称用了逗号，而逗号在中文里分的是**句子内部的分句**，放进一条昵称容易越界
（读者会等它后半句）。逗号的合法位置只有两个：**倒装的专名与头衔之间**，以及**两个分句之间**。
其余位置评估换顿号或直接删掉。按下面的判据过一遍：

| 逗号两边的成分 | 例子 | 怎么办 |
|-|-|-|
| 专名＋头衔（倒装） | `梦露，替身第一位`、`郑和，第八次随行` | **保持逗号**，这是名单式注脚的口气；换成顿号会读成并列清单，反而像两个人 |
| 名词＋名词（同位或并列） | `站姐，保管员镜头盖`、`中之人，声卡检修员` | **换顿号**：`站姐、保管员镜头盖`、`中之人、声卡检修员`——两个身份并列，顿号本来就是干这个的，比逗号少一分「还有下文」的悬置 |
| 两次陈述（两个分句） | `签售会，第三个字没说出来`、`泳池核，水还是温的` | **保持逗号**，也可以直接删掉：`签售会第三个字没说出来` 读起来更紧 |
| 动作＋插话 | `{sur}{given}路过，请睁眼` | 删逗号：`{sur}{given}路过请睁眼`（已经是提醒的语气，不需要停）。删完不顺就换顿号 |

判据一句话：**换成顿号以后，两边还读得像一个整体吗？** 像（两个身份、两件同类的东西），就换；
不像（会变成两个人、两件事，或者关系从「谁·什么职务」变成「并列」），就留逗号。
中文全角标点是唯一的写法，不要用英文逗号和英文顿号。

### 补位不要全补成否定句

「一件物 + 一个状态」是最稳的结构，但**状态不等于「坏了」**。给条目补位时，手最容易往
`没`、`不`、`断`、`缺`、`停`、`卡`、`剩`、`漏`、`错` 上滑——因为「有缺憾」看起来就有质感。
单条成立，连着读就塌：一列二十条里塞八条否定，读起来是同一句「这里出毛病了」换了八次说法。

事实上手改基线（前 10 行，约 283 条）里这类只占 **10%**，是自然的密度；一旦某一段因为「补位」
涨到 25% 以上，就是**改的人**在制造同质化，不是原文如此。

同一段里，同一条模板出现两次以上就要拆掉——`X不到`、`X没X`、`只剩X`、`X停在半空`、
`X缺一角`，都不该连着出现。补位时按这个顺序找替代，**前面能找到就不用后面的否定**：

| 换法 | 例 |
|-|-|
| 换成一个**正向**的状态 | `门缝卡住的光` → `门缝漏进一线光`（`漏` 在这里是透进来） |
| 换成**位置**，不说状态 | `旧收音机收不到台` → `旧收音机蹲在墙角`、`小云赖着不走` → `小云挂在檐口` |
| 换成**动作**，让读者自己得出结果 | `雪豹巡山不带声` → `雪豹巡山踩雪`、`夏雪不化` → `夏雪压着花` |
| 换成**量的形态** | `雾凇压断枝` → `雾凇压弯枝` |
| 仍要留否定时，**换掉那个最常见的字** | `小夜不长` → `小夜还长`；`缺鼻尖` → `掉了鼻尖` |

**还剩语气没落地的，交给尾饰。** 否定词有时是这句话的全部内容（`她从不先开口`），
这时删掉否定会把整条掏空——正确做法是**把否定删到只剩「还差一点」的感觉，让尾饰接手**：
`她从不先开口` → `她先开口~`、`秋千停在半空` → `秋千晃到一半~`、`手机只剩一格电` → `手机一格电~`。
尾饰在这里不是装饰，是**替代了一个说不出口的否定**。

判据一句话：**这句话如果换一个不懂梗的人来补，他也会补成「不好/少了/坏了」吗？**
会，说明这条的写法是大路的，换掉。

**换法本身也会变成新模板。** 去掉否定不等于去掉了同质化：把八条否定句全换成「X到一半」，
只是换了一个同样密的句式。所以改完要**再查一遍你刚用的那个句式出现了几次**：
`X到一半`、`X停在`、`X只剩`、`X顺着/沿着`，只要同一段里出现两次以上，就说明你只是在挪位置。
判据从「这一条好不好」升级成「**这一条和它左右两条像不像同一个人写的**」——
一列的目标是读起来像同一个人在说话，不是每条都漂亮。

第 8 级（重写）只在「删完包装、换完实物还是空」时才动。有一条比它更早该停手：
**这条已经靠氛围或字形立住了，拆成实物反而变钝。**

- `碧雪曲`、`墨染青丘`、`碧海潮`、`夜樱`——四五个字就把一处景立完，加一个实物名词就散架。
  这一类的判据是：**删掉任何一个字，意思就散**，说明它已经绷紧了，不该再动。
- 反面：`薄雾倾城`（`倾城` 是形容词，落到一个「谁的」上就空）→ `雾还没散`；
  `橙风` 太寡，可以补一点齿感 `橙风带橘皮味`，但要保留 `橙风` 这个原有的词。
- 分界不在字数，在**画面有没有写满**。同样六个字，`薄雾倾城` 空（`倾城` 悬着没落到东西上），
  `半城烟沙掩浮华` 却已经把景写完——`烟沙` 和 `浮华` 互相接住，删掉哪一半都散。
  这类属于同一条底线，不动；硬改（`烟沙掩住半座城`）只是把一句写完的话重说一遍。
- 改写时**保留原词**是底线：`橙风` 里的「橙」是这一条的唯一识别度，换成「风里带股橘皮味」就等于换了另一条。

**补一个状态，不等于给句子补一个动词。** 这一节和「尾饰」一节合起来看：一条已经写完的短语，
缺的往往是收束（一个 `~`、一个括号），而不是缺一句谓语。给 `彩虹泡泡` 补成 `彩虹泡泡破了`、
给 `梦之翼` 补成 `梦之翼折了`，看起来「具体了」，其实是把四字短语换成了一句带「了」的叙述——
字数变多、分量反而变轻。**这类两到四字、本身读音就齐的条目，优先判「不动」或「挂尾饰」，
不要往后走第 3 级。**

### 哪些列不怎么吃头衔式

头衔法是主推句式，但它不是全表都必须用的模板。**音乐/美术、天文地理两列基本不用头衔式**，
事业、现实日常里也只有少数条目是头衔。这些列靠的是**一个具体的物、一处具体的景、一个具体的动作**
立在名字里，加了职务反而把反差的力道削平了。

- 音乐/美术：写具体到某一小节的错音、某一支落灰的琴、某一块脏灰（`肖邦夜曲断在第四小节`、
  `节拍器卡在84`、`水彩盘里的脏灰`、`梵高的另一只耳朵`）。不要写成「音乐家」「画家」。
- 天文地理/人类学与玄学：只写**一处地貌或天象**（`北回归线-起雾`、`峡湾尽头-灯塔`、
  `海平面-以下`、`山顶-界碑`、`沙漠公路上的补丁`），或**一条历法与信仰的刻度**
  （`子时生人`、`谷雨`、`霜降`、`青丘有狐`、`麟踩过的土`）。不写「地理学家」「风水师」。
  **位移、口岸、换乘、旅途心情已不在这列**——原「地理/旅行」拆分后，那半边并入事业（见上）。
- 事业里的体育与竞技：写**运动服、场地、目标、赛程这些整体**（`阿禾穿上主场球衣`、
  `泳池主场看台`、`赛程进入最后一轮`），不写汗、秒表、鞋印这类残片；**约一成**可以写成头衔
  （`阿笙执哨全场`），其余走具体动作。

这三处的共同点是：**画面比身份更值钱**。判据是这行字能不能让人看见一个东西或一处地方；
能看见的，就不要给它加头衔。

## 硬约束：不用阿拉伯数字，不用「了」

这一节先于下面的「精修：一台八级手术」——任何一级动手之前先过它。

这两条最容易破，而且一破就露馅。但表里确实留着带阿拉伯数字和带「了」的条目，
说明它们**不是绝对禁令，而是有明确例外范围的禁令**——例外范围写在各节末尾，别扩大。

**不用阿拉伯数字。** 这条只管 `0~9`：`加班到9小时`、`通勤2小时`、`节拍器卡在84`。
中文数字（`一`、`七`、`第三圈`、`三更`）是汉字，不在这一条的管辖内，形态上算纯中文。
数字在这里几乎总是「我从外面给它标了个刻度」，而不是「她看见的东西」。
一有阿拉伯数字，昵称就从现场退回到报表，换来的精确是假的，代价是画面消失。

**上层判据：展示近段状态，不展示瞬时观察及其反思。** 这才是「不用数字」背后真正的一条，
同时管阿拉伯数字和中文数字。昵称可以写**一段时间里积成的状态**（跨度、进度、存量、身份），
但不要写**某个瞬间看见的一幕，再替这一幕下个判断**：

| 瞬时观察＋反思（不要） | 近段状态（可以） | 差在哪 |
|-|-|-|
| `日记停在第7天` | `7天完工的日记` | 前者看见「停在 7」并感慨断更；后者写 7 天里做成的一件事 |
| `还剩一半的蛋糕` | `尚存50%青春` | 前者是看一眼蛋糕得出的余数；后者把存量写成仍持有的一段状态 |
| `出差第五天` | `酒店枕头收藏家` | 前者给日子标刻度；后者写这趟差事积下来的东西 |

判据只有一句：**这条数字是在报「此刻我看到什么、它说明什么」，还是在写「这段时间积成了什么」。**
是前者就换掉——换成动作、状态或实物（第 3 级「把词换成那件东西」），不要只换字形。
**中文数字滥用就靠这一条从上层避免**，不靠「不用数字」（那条只管 `0~9`），
也不要为了守规则或凑配额在中文数字与阿拉伯数字之间互换字形；
反过来把阿拉伯数字改成汉字同样是假精确（`节拍器卡在八十四`）。

| 带阿拉伯数字 | 不带数字 | 怎么办 |
|-|-|-|
| `加班到9小时` | `加班久到机器发烫` | 数字是假刻度 → 换成状态 |
| `出差第5天` | `酒店枕头收藏家` | 数字是假刻度 → 换成从里面看见的东西 |
| `月薪3千的觉悟` | `月薪撑不起的觉悟` | 数字删掉后补一个动作 |
| `通勤2小时` | `通勤单程`（现续为 `通勤单程有座`） | 数字可删 → 删 |
| `节拍器卡在84` | `节拍器卡住` | 数字可删 → 删（**不要改成「八十四」**，那是把假精确写得更假） |
| `国境线外3公里` | `国境线外` | 数字可删 → 删 |
| `第4棒替补` | `接力替补` | 数字可删 → 删 |
| `航海王第1080话` | `航海王最新话` | 数字是引用的一部分 → 交给下面例外 |

同一张表里 `加班到第九小时`、`出差第五天`、`国境线外三公里` 这类中文数字写法有同样的假刻度毛病，
但归上层判据管（视角、第 3 级换词），不靠把它们改成阿拉伯数字来治，也**不算形态上的数字**。

**例外：数字本身**就是那个东西，删了条目就空掉。三种情形：

- 编号与门牌：`波斯波利斯05号柱`、`娜娜707号房草莓杯`、`环岛路108号街区`、`104路夜班车`、
  `奇点档案馆404号最后读者`、`SCP-4000`——编号属于那件东西的名字。
- 年份与纪年：`金帐汗国1242雪`——年份是一个时代的名字。
- 外语名里的数字：`Etherea7`——它是外文构词，不是计数。
- **显示型数字**（角色系列常用）：`御坂1234号`、`宝可梦151号收服球`、
  `最终幻想7存档维护员`、`练习生第101天`、`追光灯下3排尘埃`——作品内的编号、血量、
  等级、排数、图鉴号。这类数字是「屏幕上显示出来的那一个」，不是叙述者从外面标的刻度，
  在角色/游戏/文娱语境里很常用，**不删**，形态上单列为「中文 + 非尾注数字」（见「三形态配比」）。

**判据是「显示」还是「刻度」，而不是「有没有阿拉伯数字」**：这是上面「近段状态 vs 瞬时观察」
在阿拉伯数字上的执行口径。删掉数字后仍能认出是同一件东西、
但数字本来是屏幕上那个值（编号、血量、等级、次数，即一段持续状态里的读数）→ 留；
数字是我从外面给日子标的刻度（`加班到9小时`、`国境线外3公里`）→ 删。
前一种在后三类按配比留到约 5%，意象系列不写数字，不按这个配额。
中文数字同样按这套判据看视角，但**形态上仍是纯中文**，不占这个配额。

**句末的阿拉伯数字是尾饰，不是刻度。** 数字在句中当量词是刻度（`加班到9小时`），挂在句末却是**语气**
——它和 `~`、`…` 干的是同一件事：把话悬住。所以判据先问位置：

| 位置 | 例子 | 怎么判 |
|-|-|-|
| 句中，量后面的那个数 | `加班到9小时`、`国境线外3公里` | 从外面给日子标刻度 → 删 |
| 句末，单独挂着 | `反正也追不7`、`晚安404` | 读者不拿它计数，只当这条没说完 → 尾饰，留；**形态上算混合**（非中文字符的一种），不算「中文+非尾注数字」 |
| 句中，是屏幕显示的值 | `御坂1234号`、`宝可梦151号收服球`、`追光灯下3排尘埃` | 编号/血量/排数，数字是那件东西的一部分 → 留；形态上单列为「中文+非尾注数字」 |
| 句子本身就是一个编号 | `104路夜班车`、`金帐汗国1242雪` | 数字是那件东西的名字 → 上面例外，同归「中文+非尾注数字」 |

句末这类不超过全表的一小撮，**不要当作新的装饰去批量添加**（见「尾饰」一节的「一个符号就够」）。
表里的数字一律指阿拉伯数字；`第三圈`、`七号线` 是汉字，形态上算是纯中文，滥用按上层判据处理。

**不用「了」。** 「了」是叙述的收尾，它把昵称写成一个已经讲完的小故事：
`球鞋底磨平了`、`琴凳矮了半寸`、`画框背后写着别人的名字`、`边境小镇的邮局关门了`。
删掉它，句子就停在状态上，不再是叙事；同时长度也会自然缩短，回到一个称呼该有的分量。

| 带「了」 | 不带「了」 |
|-|-|
| `球鞋底磨平了` | `球鞋底磨平` |
| `琴凳矮了半寸` | `琴凳矮` |
| `画了一半就停笔` | `画稿未干` |
| `通关文牒黄了边` | `通关文牒黄边` |
| `BOSS打过了` | `BOSS已过` |
| `暗夜骑士的猫步🐱✨` | 删 emoji 不够 → 整条重写 |

**例外（20 条，约 1.6%）**：三类，其中前两类是口吻，第三类是被规矩卡死的。

- 口语态度：`算了`、`学到了`、`已阅`、`在忙` 这类短小网感——「了」在这里不是完成态，
  是一个决定或一个懒。整列 4/27 带「了」，是**这一列的正确写法**，不要改。
- 固定说法：`偷偷喜欢很久了`、`为你留了半边天`、`想见你的第很多天`——删「了」句子就散架。
- **「了」带出一句后果**：这是唯一该主动写的「了」。判据不是「有动作」，而是
  **这个动作有没有把日子弄乱**——留「了」的那半句必须接着说出代价、余波或后果。

| 只是叙述 | 带出后果 |
|-|-|
| `狗子拆了沙发`（拆完就没了，读者不知道这有什么要紧） | `狗子拆了沙发我没处躺` |
| `喂了三年的流浪`（收养是一个动作，不是一个处境） | `喂了三年的流浪还不让我摸` |
| `它不认识我了`（停在伤感上） | `出差回来它不认识我了` |

  一条只有「主语＋动作＋了」，没有后半句的后果，就不算例外，该改回状态式
  （`客厅里的沙发残骸`）。**「了」不是叙事时态，是一句抱怨的引子**；一整列都这么写才算成立，
  单独一条这么写，读起来只是一个没讲完的句子。

**换词时「了」会顺手溜回来。** 去否定、去损坏词的时候，最省力的改法往往是把它改成完成态
（`算命的说不旺` → `算命的改口了`、`剩半盒的酸奶` → `酸奶少了一盒`）——读着顺，但一条「了」又回来了。
改完必须复核**全表含「了」的条数有没有变**，变了就说明换法在偷懒。

**「了」可以先交给尾饰。** 判过一遍「这个「了」有没有带出后果」之后，还剩一批是拿它当停顿用的
（`草莓奶油塌了`、`算了`、`不聊了`）。这类不必硬删成 `塌`、`算`、`不聊`，换成 `塌成滩`、`算了。`、
`不聊了~` 更省事：**「了」在句中是时态，在句末是语气**，句末的这份语气只有标点能接（见「尾饰」）。
注意尾饰接的是**语气**，不是替句子补后果——`狗子拆了沙发` 那种该补后半句，挂一个 `~` 也没用。

第一条省着用：一条昵称里既有「了」又带尾饰，就是两个收尾，取其一。

**`网络meme` 列暂不套这两条。** 这类条目的字面常常就是梗本身——`功德+1+1+1` 的加法、
`汗流浃背了` 的「了」都在梗的写法里，删一个符号、删一个「了」，梗就认不出来了。
这一列目前没有好标准（梗的识别依赖它原样的字符），所以**先不动，等这一列单独定规则**；
别的列还是按上面两条走。

两条规则的共同点：**昵称是标签，不是句子。** 数字与「了」都是句子的零件（量词、时态），
放进标签里就会把标签撑成一句话。判断方法很简单——删掉这个数字、这个词，意思有没有变？
没变，它就是多余的。**代价则是唯一让「了」留下来的东西**：删掉以后那点麻烦没了，
说明它该留；删掉以后什么都没变，说明它本来就是多余的。

## 精修：一台八级手术

上面几节说的是**句式**，这一节说的是**打磨**：什么叫一条昵称「有点糙但很对」，什么叫「干净但平庸」。

前 4 行是逐条手改过的，分类未必对得上，但**文学与风格化没有问题**。把它们和改之前的原文逐格对齐，
得到 21 组对照，再加上运营账号整列 53 条的整列重填，可以看出手改不是一种手法，而是**八种**，
而且有先后顺序：先删包装，再拆句子，再换内容，最后才整条重写。**顺序不能乱**——
给一条还带着 `（如果）` 和数字的条目补实物，等于白改。

下表是判**用什么手术**的序，不是判**归属**的序（归属见最前面的判定顺序）；一列该不该整列重填，
见下面「尾巴：写坏了怎么救」里的「三档返工」。

| 级 | 动作 | 判据：什么时候进这一级 | 实测占比 |
|-|-|-|-|
| 1 | 删掉外面的包装 | 有虚词括号、emoji、`°`、`.` 尾巴、`_后缀`、官方口吻词、冒号 | 38% |
| 2 | 拿掉句子的零件 | 有阿拉伯数字、编号、多余的「了」、多余量词 | 33% |
| 3 | 把词换成那件东西 | 内容是标签或感想，读不出「那里有什么」 | 33% |
| 4 | 熟词降一格 | 用了专名，但只用了它最体面的那一面 | 33% |
| 5 | 给这行字一个主人 | **只对运营账号与事业**：不落人名它就不成立（落名不用冒号与括号） | 52% |
| 6 | 换一个知识点 | 用的是大路人人都认得出的那个典故 | 19% |
| 7 | 减字与「的」字换位 | 虚词、语气词、双重修饰把一行撑到了 9 字以上；或整行超过 14 字 | 33% |
| 8 | 重写 | 上面七级都救不回来 | 38% |

第 5 级的两列落名要求不同：**运营账号整列都要有主人**（只有系统文案/口吻句是例外），
**事业只在有署名需要时落名**，不要求整列。两列的落名写法与硬约束完全相同。
运营账号落名的条目里，**写死的昵称或化名与占位符各占一半**（见第 5 级）。

运营账号在第 5 级之后还有一道**变短**（5b），因为它是唯一一列现在整列都超长的。
另外三条硬约束不分级、先于全部八级：**不用冒号**、**括号只装可省略的内容**、
**不用阿拉伯数字与「了」**（各带例外）。

一条可以同时用好几级，所以合计超过 100%。反过来，**只用到第 1 级就停手，是这轮返工的主要原因**：
`（如果）靖康雪未落` 删完括号很像样，但真正让它立住的是后面「雪未落」这个还没发生的事实；
`Anime💖天使` 删掉 emoji 只剩 `Anime天使`，仍然是一层滤镜——它被换成了 `二次元见习天使`，
「见习」这个不体面的身份才是新东西。

### 1. 删掉外面的包装

装饰是围着内容转的包装，删掉它不损失信息；但**删完要检查内容本身还站不站得住**。

| 包装型 | 删完后 | 删完还不行，进下一级 |
|-|-|-|
| `（如果）靖康雪未落` | `靖康雪未落` | 站住了 |
| `C位出道·失败实录` | `C位出道失败实录` | 站住了 |
| `阿不思·邓布利多肉` | `邓布利多肉` | `邓布利多肉植物` |
| `Anime💖天使` | `Anime天使`（仍是一层滤镜） | `二次元见习天使` |
| `官方认证摸鱼号` | `摸鱼号` | `{given}今天不营业` |

- `·`、`°`、`.尾巴` 属于同一类装饰包装。现有的 `软乎乎·暖宝宝`、`布朗宁.`、
  `绫波零，同步率观察员`（此处逗号是对的，属于倒装）都该分清：**倒装的全角逗号保留，装饰性的点删掉。**
  （`贝壳发夹°`、`断了齿的木梳·` 已按这一条清成 `贝壳发夹`、`缺齿的木梳`。）
  `-` 和 `_` 不在这类里（见「符号的位置判例」），它们是断句/署名符号，不必按装饰删。
  `°` 有两种用法：夹在词中间（`姑获鸟°夜行`）是装饰，删；挂在句末（`夜未央°`）可能是尾饰，
  先按「尾饰」一节判一遍，再决定删还是换。
- 运营账号里的 `_Official`、`bot`、`机器人`、`官博`、`公众号：`、`号`、`协会`、`中心`、`窗口`、`处`
  也是包装，而且是**机构腔**：`快乐水质检员_Official` → `快乐水质检员{given}`，
  `已读乱回机器人` → `{given}已读乱回bot`（这一个保留了 `bot`，因为它是口吻不是头衔）。
  `channel` / `official` 作**账号品类标签**时少量留 3 条（`阿栀已读乱回channel`、
  `变小公告_团子channel`、`每晚十点_EllieOfficial`）：是号自己在标品类，不是机构在认证；
  只贴在口吻末尾或名字后面，**不做署名分隔**（`_Official` 那类前缀仍清掉），也不再加。

### 2. 拿掉句子的零件

阿拉伯数字、「了」、量词都是句子的零件（见前面两条硬规则）。这一级只做减法，不改动词；
中文数字是汉字，按上层视角判据处理，不在这条的减法清单里。

| 原件 | 减法后 | 若是「数字本身是假的」 |
|-|-|-|
| `加班到9小时` | `加班到9小时`（删不动） | `加班久到机器发烫` |
| `出差第5天` | `出差第5天`（删不动） | `酒店枕头收藏家` |
| `试岗期第七天` | `试岗期中途` | — |
| `月薪3千的觉悟` | `月薪的觉悟`（空） | `月薪撑不起的觉悟` |
| `工资条撕了` | `工资条`（太干） | `已阅不回工资条` |

注意这张表的第三列：数字在这里不是句法问题，而是**视角问题**。`出差第5天`、`试岗期第七天`
都是从外面给这段日子标了个刻度；手改换成了**从里面看见的东西**（床头那摞枕头、进程到一半）。
所以第 2 级对数字只能做一半工作，剩下一半要交给第 3 级。中文数字写多滥用也走同一条路——
从上层换掉「标刻度」的视角，而不是靠「不用数字」这条去禁它。**不要为了守规则把阿拉伯数字改成汉字**
（`节拍器卡在84` → `节拍器卡在八十四`），那是把假精确写得更假；
也不要反过来为了凑形态配额把中文数字改成阿拉伯数字。

### 3. 把词换成那件东西

最要紧的一级。**写「那里有什么、它现在是什么状态」，不要写「关于它的感想」。**
一个具体的、甚至有点脏的实物，胜过一串漂亮的抽象词。

| 停在标签/感想 | 换成那件东西 |
|-|-|
| `工资条撕了` | `已阅不回工资条`（撕这个动作换成「已阅不回」的流程） |
| `听见Miku的歌` | `耳机里只剩Miku`（把「听」换成「只剩」） |
| `爱在黎明前24小时` | `黎明前24帧`（换时间单位＝换成一个行业里的人才说的东西） |
| `白蛇借伞·断桥雨` | `断桥借伞人`（从「场景」换成「在场的那个人」） |
| `官方认证摸鱼号` | `{given}今天不营业`（从「认证」换成「今天的实际状态」） |

**「一件物 + 一个状态」是这个项目里最稳的结构**：`球鞋底磨平`、`护照盖章将满`、
`石膏像缺鼻子`、`水彩盘-调成脏灰`、`画框背后写着别人的名字`、`行李箱轮子坏一只`。
这批手改里还试出了它的两个变体，都是**把名词换成同一个位置上的更具体名词**：

- 换单位：`24小时` → `24帧`（同一段时间，换成一个只在片场才用的计量）
- 换物：`旧货市场` → `旧物店`，`U型枕` → `红眼航班`，`三脚架3号` → `测量三脚架`
  → `三脚架-定准点位`（末一步是情绪三分时从器具改成手艺，`-` 是配比调整时补的断句）

### 4. 熟词降一格

专名（肖邦、梵高、Miku、邓布利多）不是不能用，而是**要把它放进一个不体面的处境**。
名人本身是空的，名人的某个狼狈细节才有戏。

- `梵高的耳朵`（不是「梵高的星空」）
- `洛天依的钢琴师`（不是「洛天依的歌声」）
- 反向也成立：**中文里太熟的典名，可以换回它的原文名**——`天狼` → `Sirius.`，陌生感就是降格
- 同理 `邓布利多肉` → `邓布利多肉植物`：名字没换，把它从「肉」放进「多肉盆栽」的处境里

对比：`星月夜的蓝` 是漂亮但空的；`梵高的耳朵` 是有实体的。

### 5. 给这行字一个主人

**只对运营账号列生效**，但这一列**几乎没有例外**：除系统文案与纯口吻句，每条都要落到一个人名上。
所以运营账号的润色顺序和别的列相反：**先落人名，再看句式**。

**署名一半用固定名，一半用占位符**：一半写死昵称或化名，一半留 `{given}` / `{sur}`。
固定名是**昵称自带的名字**，不是从姓名表掷出来的——中文昵称（`小满`、`阿栀`、`知秋`、`团子`、
`阿梨`）或通用外文化名（`Mika`、`Rin`、`Momo`、`Sora`、`Aki`、`Ellie`、`Nia`、`Saki`）。
判据：两到三字、像随手起的网名、不带出处、**不指向具体作品角色或在世真人**；同一个名字不要在同一列
重复出现（28 个固定名各用各的）。写固定名时占位符要整个去掉，不能写成 `阿{given}` 这种半固定。
占位符那 24 条**姓与名仍要配**，其中 9 条落 `{sur}`（三到四成），不因为降了一半就只堆 `{given}`。

落名有四种写法，固定名与占位符都按这四种走，**全都不用冒号，也不用括号当分隔**：

| 写法 | 占位符例 | 固定名例 | 说明 |
|-|-|-|-|
| 前置署名 | `{given}今天不营业`、`{given}只发天气` | `小满今天不营业`、`Mika只发天气`、`阿栀已读乱回channel` | 最短，最像个人号，首选 |
| 后置附名 | `快乐水质检员{given}`、`屋顶承重员{given}` | `快乐水质检员小葵`、`今天歇业_阿桐`、`深夜回收站_小雾` | 头衔＋名字，不加标点 |
| 所属 | `{given}的影子播报台`、`{given}的日常发疯记录` | `小柚的足迹长度公示`、`阿梧的影子播报台` | 「的」字结构，别满列都是它 |
| 全名 | `{sur}{given}的影子播报台` | —（固定名用全名会过长，此写法只留给占位符） | 姓只能放在全名里，不能单用（`{sur}的影子播报台` 读着别扭） |

**不能再用的两种署名**（现有存量要改）：

- **冒号署名**：`公告：本月{given}不再变小`。冒号在昵称里是少见的字符，显示端未必吃得住。
  改成下划线：`公告_本月{given}不再变小`——同样是「标题｜内容」的口气，但只有一个 ASCII 字符。
  同理 `每晚十点：{sur}{given}` → `每晚十点_{sur}{given}`、`晚上出门关灯：{given}提醒` →
  `关灯提醒_{given}`（顺手也做了第 7 级）。
- **括号署名**：`此处有巨大不明生物（{sur}氏）`、`收到请仰望（{sur}）`。这是把括号当分隔符用，
  而括号只装可省略的内容（见「括号只做一件事」）。
  → `此处有巨大不明生物_{sur}氏`，或者干脆并进句子：`{sur}氏此处有巨大不明生物`。
  `{sur}可（身高每天都在更新）` 是**合法**的括号用法（可省略），留括号，只压到 13 字以内：
  `{sur}可（还在长）`。

### 5b. 运营账号还要变短：现在的长度是错的

第 5 级只解决了「有没有主人」，没解决「长不长」。这一列既长、又爱带括号和冒号，三样都要收
（冒号应清零；固定名条目按字面字数算，比占位符短）；下表是诊断口径：

| 项 | 现在 | 应该 |
|-|-|-|
| 长度 | 均长 14.6，最长 22 | **上限 18 字**（按 `{sur}`/`{given}` 占位符原样计），靶心 10~14 字。这一列有一半条目带占位符，比别的列多给 4~5 字：`{given}正在变小` 写成 `公告_本月{given}不再变小` 是 13 个字符、渲染后也才十一二字，不该为了「短」把「公告」这类口吻削掉；固定名条目按字面字数算，写死后更短 |
| 括号 | 12 条 | 只留可省略的内容（`{sur}可（还在长）`、`{sur}遥（一步顶一周）`）；**拿括号当署名分隔的**（`（{sur}氏）`、`（{given}）`、`（{sur}签发）`）一律改 `_`。剩下 3 条为上限 |
| 语义 | — | **别名不能与事实打架**。`匿名用户_{sur}` 透露了姓就不叫匿名；`{sur}氏屋顶视野长期招人` 里「氏」已经是第三人称，前面再挂全名就重复 |
| 冒号 | 7 条 | 不用，改用 `_` |
| 符号 | 94% 有符号 | 符号只承担署名与断句，不做装饰。一条只用一种 |

**变短不是删字，是换口吻**：不再写「关于她身高的说明」，而是写成一个只发一件事的号。
试写池（不是终稿，只用来定口吻）：

| 口吻 | 样子 |
|-|-|
| 只发一件事 | `今晚只报天气`、`每天量一次影长`、`我只在睡着时发帖`、`抬头这件事在更` |
| 解释自己 | `本人比看起来小`、`抬不起头所以不回`、`一步能顶你一周`、`影子和我不符` |
| 打招呼 | `路过请抬头`、`关注前先抬头`、`看得见我就回` |
| 嘲讽 | `低头是你的事`、`别拿我跟楼比`、`抬头再跟我讲话`、`你们在几层啊` |
| 系统文案 | `该账号已停止运营`、`内容已被屋顶挡下`、`本条发自云层之上`、`此号暂不接单` |
| 落名（短） | `{given}今天不营业`、`{given}只发天气`、`屋顶承重员{given}`、`身高争议方{given}` |

这一列**还没有公认的好示例**。样板只能从「整列读下来像不像同一个人在说话」这件事上认，
不能从单条上认——单条再好，一列四十条都是同一个句式，就是失败的。

### 6. 换一个知识点

这一条是这一轮**新加的**，来自 `阿不思·邓布利多肉` → `邓布利多肉植物` 和 `Tree上种个笑话`
→ `树梢藏个笑话`。判据不是「有没有典」，而是**用的是不是人尽皆知的那一面**：

- 哈利波特有几百个角色，手改从「阿不思」换到「邓布利多」再换成「肉植物」——三次都在换知识面。
- 历史典故列同理：不要停在三国的「江东子弟」，要走到 `孟尝君门客夜行`、`保管汉谟拉比柱的第一任`、
  `元祐党人榜末位` 这种**知道的人不多、但知道的人会笑**的位置。
- 换知识面时**别碰红线**：真实的在世人物、宗教与民族话题一律不碰，`ikun` 这种就被换掉了。

### 7. 减字与「的」字换位

同一句话，换一个语法位置，长度和分量都会变。手改里最典型的三组：

| 原句 | 改后 | 改了什么 |
|-|-|-|
| `爱丽丝，落体测试员` | `爱丽丝坠落指南` | 去掉倒装与头衔，`落体` → `坠落`，变成书名的口气 |
| `半颗糖的甜` | `海盐太妃糖` | 「的」字结构换成并列名词，甜有了具体的咸味来源 |
| `五金店深处的抽屉` | `五金店抽屉` | 砍掉方位虚词，位置感反而更准 |
| `树洞投稿箱（已满）` | `树洞投稿已满_{given}` | 括号里不是可省略的，是正文；换成 `_` 并署名 |

**收尾必须变短**：一条昵称的字数在最后一段要落下来，不能越写越长。落名占 2~3 个字，
所以带名字的条目正文只能留 6~10 字；**运营账号放得松一点**（上限 18 字，见 5b）——它现在均长 14.6 字是错的，
不是特例（见上面 5b「运营账号还要变短」）。

### 8. 重写

七级都救不回来的，整条换掉，并且**换到另一条知识线上去**，不要在原来的句子上继续修补。

- `Sakura_Chloe` → `Bloom`（这一条在表里的位置原本是 `u`，等于把整条换成了另一条）
- `ikun` → `练习生观察员`（同一个粉丝文化，换成一个不站队、不指真人的身份）
- `∅空∅` → `空集（Null）`：符号删掉后需要一个更硬的词——`空集` 是数学名词，比 `空` 立得住
- `优` → `U。`、`岫` → `云出岫`：太短的独字要补一个落点，孤字没有位置感

### 分寸：哪些条目反而不能改得更「具体」

手改里有几条是**唯一没有做成「实物＋状态」的**，因为它们的价值在字形或口吻上：

- `Sirius.`、`Bloom`、`Bambi` 一类：纯外文靠字形，加中文反而稀释（`旧壁橱Ambry` 是例外，
  因为 `Ambry` 本身没有字形美感，需要中文给它位置）。
- `U。`、`Biu一下`：这类效果来自标点和口语，删掉就散了。
- `算了`、`学到了`、`已阅`、`在忙`：短小网感整列**保留「了」**，因为「了」在这里是口语态度
  而不是叙述时态（`算了` 不是「算」的完成态，是一个决定）。
- 运营账号的 `_`（`{given}只发天气` 不适用）：`_` 在这一列是**署名与断句**，不是装饰，
  不在第 1 级的删除范围里。但拿括号当署名分隔不在例外内——那是要改的（见「括号只做一件事」）。

### 附：四条抓质感的口诀（管「糙但很对」，不管句法）

第 1~8 级回答的是「这行字落在哪里」，下面四条回答的是「落在那里之后，字好不好听」。
它们不再并列成手法，因为**每一条都只是第 3、4 级的一次具体落笔**。

- **允许粗粝**：跑调、抢拍、卡住、磨平、断了、落灰——这些不体面的词是反差感的来源。
  警惕全是形容词的写法（`优雅的转身`、`温柔的光`、`静默的守望`），一句里没有一件东西。
- **留一点不完整**：主语省略、句子截断、只写场景的一截（`颜料洗不掉的那股腥味`、`凌晨的车站只剩广播`）。
- **戏谑靠名不副实**：称谓与事实对不上（`长信宫灯熄灯人`、`维也纳森林伐木人`），不需要另立语法。
- **熟词只在专名上降格**：`梵高的另一只耳朵` 成立，但不是所有专名都该往狼狈里写——
  `洛天依的钢琴师` 靠的是「洛天依不会弹琴」，不是她狼狈。

## 尾巴：写坏了怎么救

### 三档返工，不要一把全删重写

| 档 | 症状 | 动作 | 举例 |
|-|-|-|-|
| 轻 | 只多了包装或零件 | 只做第 1、2 级 | `（如果）靖康雪未落`、`进度条｜卡住了`、`[又在改需求了]` |
| 中 | 句法没问题，但停在标签上 | 做第 3、4、7 级 | `工资条撕了`、`听见Miku的歌`、`五金店深处的抽屉` |
| 重 | 换了三级还是空 | 整条重写，换知识线 | `ikun`、`Sakura_Chloe`、`∅空∅` |

判据只看一句：**改完之后，能不能指着一个东西说「就是它」？** 能，就停手；不能，进下一级。

括号要单独过一遍：删完包装以后，剩下的括号必须**整块删掉仍旧成立**（可省略成分）。删掉就丢信息，
说明它不是括号该装的东西——并进句子，或者换成 `_`。

### 整列返工，先看这一列的病灶在哪

这一轮 53 条运营账号是整列重填的，因为它的问题是**每一行都缺同一个零件**（署名），
所以逐条改不如整列重来。反过来，历史典故列的问题是分散的（编号、装饰、典名太熟），
只适合逐条做第 1、2、6 级，整列重来反而会把 `洛神赋临摹不走样的人` 这类好的也冲掉。

| 病灶 | 整列重填 | 逐条修 |
|-|-|-|
| 每行都缺同一个东西（运营账号缺署名） | 是 | — |
| 每行都漂在同一层（意象·情绪 41 条里 9 条是 `梦X`） | 是，只重填漂掉的那一片 | — |
| 问题分散在几种小毛病上 | — | 是 |
| 一列里有 3~5 条是标本，不能碰 | — | 是，先标出来锁住 |

### 三条不要做的事

1. **不要把阿拉伯数字改成汉字，也不要把中文数字改成阿拉伯数字。**
   `节拍器卡在84` → `节拍器卡在八十四` 是把假精确写得更假，正确做法是删成 `节拍器卡住`；
   反过来 `时间简史第七页看守` → `时间简史第7页看守` 只是把汉字换成数码，没有解决任何问题。
2. **不要给已经有实物的条目再加 emoji。** `画框背后写着别人的名字` 加一个 🌙 就回到平庸，
   符号只用在靠字形取胜的条目上（外文、编号）。
3. **不要为倒装而倒装。** `帝国拯救者凯撒` 是自然成立的前置定语，`凯撒，帝国拯救者` 是名单写法，
   两者都对；但把动作硬拆成前置定语（`真迹看管兰亭序`）就不通了。
