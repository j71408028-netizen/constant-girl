# 副本内的地点与参照物（面向作者）

> **这一篇回答什么问题**：这一章「发生在哪儿」怎么写、尺寸换算句里的参照物从哪来、什么时候才会冒出一句「约等于 XX 的 1.02 倍」、结局又把她送到哪。地点不参与寻路，也不参与解锁——它只负责让 AI 知道这一章的空间背景。
> - **写方案的作者**：§1～§6 是照写的部分（字段在 §2，参照物在 §3）。
> - **写完没出现换算句**：先看 §4 的两条触发条件，再看 §9 的校验表。
> - **改代码的人**：§7 内部实现、§10 验收。
>
> 相关页面：地址怎么写、怎么注册 [../address_system.md](../address_system.md) · 章节与触发器字段 [script.md](script.md) · 换算句怎么进提示词 [prompts.md](prompts.md) · 主世界里的地标配对 [../report_selection.md](../report_selection.md)。

## 1. 地点是写死的，地址只负责声明

副本里没有移动、没有寻路，也没有「从 A 走到 B」的移动叙述：这一章发生在哪儿，是作者写死的。所以地址在副本里不承担**求解**职责，只承担**声明**职责。

三条用途都立在这件事上：

| 用途 | 读什么 | 不声明时 |
|---|---|---|
| 展示 | 章节 `place` / `address` → 提示词里的地点行（§5） | 什么都不显示 |
| 参照物 | 章节 `scene_landmarks` + `common_private_name`（§3） | 空池，不产生换算句 |
| 传送 | 结束章节的 `exit_address` 写回角色位置（§6） | 位置不变 |

一条硬推论：**参照物是逐章可选的增强**。什么都没配的章节没有候选池，也就不产生换算句——它不会回落到全局全量。

## 2. 字段怎么写

独特地标内联在章节里，编辑器里像演化修正一样逐行添加：

```json
{
  "name": "第三章",
  "place": "黑塔脚下的集市",
  "address": "1e3_1e2_1e1@HD!RW-CN1-HD",
  "scene_landmarks": [
    {"name": "黑塔", "size": 468, "dimension": "vertical"},
    {"name": "护城河", "size": 40, "dimension": "horizontal",
     "horizontal_type": "length"}
  ],
  "common_private_name": "HD",
  "exit_address": "1e3_1e2_1e1@HD!RW-CN1-HD-9"
}
```

| 字段 | 位置 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| `name` | 地标 | str | 必填 | 直接进提示词 |
| `size` | 地标 | float | 必填 | 米；`vertical` 为高度，`horizontal` 为长度 / 宽度 |
| `dimension` | 地标 | str | `vertical` | `vertical` / `horizontal` |
| `horizontal_type` | 地标 | str | `length` | `horizontal` 时用（`length` / `width`） |
| `place` | 章节 | str | `""` | 展示名；提示词与窗口都用它 |
| `address` | 章节 | str | `""` | 取景地址（完整地址）：地点行与展示用，**不再筛地标** |
| `scene_landmarks` | 章节 | list | `[]` | 本章在场的独特地标（建议 ≤5），全部按独特地标换算 |
| `common_private_name` | 章节 | str | `""` | 常见地标的过滤私有名；空 = 不使用常见地标 |
| `exit_address` | 章节 | str | `""` | 结局传送目的地（§6） |

`scene_landmarks` 缺省 `[]`、`common_private_name` 缺省空——什么都没配的章节没有候选池。已退役的字段（方案级 `scene_landmarks`、章节级 `landmarks` 白名单）读到即按没写处理，校验器报 warning，清单见 [数据模型](script.md) §13。

写坏的形状不会让运行中断：`normalize_chapter` / `normalize_scene_landmarks` 会把非数组、非对象、类型不对的条目归一回默认值，坏的那一条被跳过，其余照常。

## 3. 参照物从哪来：两条互不相通的路

```
本章独特地标（章节 scene_landmarks）
  ∪ 私有名一致的常见地标（仅当 common_private_name 非空）
```

- **独特地标 = 章节内联配置（强控制）**。一章里在场合乎逻辑的独特地标本来就少（建议 ≤5），由你在 `scene_landmarks` 里写明名称与尺寸；写明了就算与她在场。数值就地写、不引用全局清单——清单里删掉一条不会再牵连任何章节。
- **常见地标 = 私有名过滤**。`common_private_name` 填了私有名时，全局池里**完整地址带同一私有名**的常见地标进池（常见地标挂在世界下，声明私有名就等于声明了那个世界的常见参照物）；留空就是不用常见地标——私有名是常见地标的**唯一**通道，不是「进一步收窄」的可选项。

四种组合的结果：

| `scene_landmarks` | `common_private_name` | 候选池 |
|---|---|---|
| 空 | 空 | 空池（不产生换算句，**不回落全量**） |
| 有 | 空 | 只有本章独特地标 |
| 空 | 有 | 只有私有名一致的常见地标 |
| 有 | 有 | 并集，同名以独特地标为准 |

「私有名一致」的定义是 `parse_full(地标完整地址).chunk == common_private_name`。私有名的字符规则与地址约束段一致：字母 / 数字 / 下划线，≤64 字。**不做米数阈值，也不做空间相配**——私有名就是你点名世界的方式。

> **私有名填错 = 匹配不到**（池子空，或缺了那批参照物），校验器会报 warning；空池也是合法答案，不算 error。显式标成 `portable` 的常见地标不参与过滤（它们没有可解析的完整地址），所以别指望靠它兜底。

## 4. 什么时候会冒出换算句

本章候选池交给尺寸匹配，取最接近的一条（`order="match"`，只取 1 条）：

```
本章候选池 → get_comparisons(order="match", limit=1)
  ├─ 有候选 → 换算句
  └─ 没有   → 不产生换算句（正文照常推进）
```

触发途径有两条，独特地标两条都通，常见地标只走第一条：

1. **上一段正文提到身体部位**：部位词出现在上一段，就按最接近的从本章池子取一条对比。
2. **她与地标同时在场**（独特地标独有）：最近一或两个显示段落内，她的名字（或「她」）与地标名字同段出现，或分处相邻两段，就算「同时在场」，下一轮提示给出该地标的身高对比。这是判定原则，不是提示词措辞——进提示词的只有对比句本身（「她的身高 X，约等于黑塔高度的 1.02 倍」）。比例超出可比范围、或上一轮刚提示过同一地标时，不重复。

其余几条规则：

- 不返回「档位」，也没有任何「能否继续」的判断读它——推进由章节与触发器决定；
- 名字命中全局屏蔽词（`blocked_words`）的条目按现状跳过；
- 体位筛选（`vertical` / `horizontal`）沿用尺寸匹配的既有规则；
- 候选池按章节名缓存，切章失效（身高变化不影响池子）；
- **空池就是空池**：参照物配空时不产生换算句，也不回退全量。

换算句还有第三个固定去处：文本校准块的「尺度」行。校准块每轮给出当前坐标、介入度 / 破坏性谓词（只保留客观状态，不含描写口径与视角）与尺度上限；尺度行复用同一个换算句，没有换算句时只写身高，**绝不从别处补场景词**。深浅只由坐标决定，与方向的符号无关。

## 5. 地点怎么显示

- **`place` 优先**，没有就取地址的紧凑写法，两者都空则什么都不显示。作者起的名字总压过地址原文——写了 `place` 的章节，不会把带精度说明的地址串漏到界面上。
- 提示词里，`当前章节：…` 之后按需追加一行 `当前地点：…`（仅在非空时）。虚构章节不写地址，这一行就不出现。
- 窗口侧的会话访问器包的是同一个函数，留给组件用；目前只有提示词在读地点，还没有组件消费它。地址写进提示词的取舍见 `docs/Dungeon/architecture.md` 的副本地点一节。

## 6. 结局传送

`exit_address` 决定「她出来后站在哪」，是副本改写主世界位置的**唯一**入口。

| 情形 | 行为 |
|---|---|
| 结束章节 | 组装结算字段时带上 `chapter.exit_address` |
| 结算 | 能解析成完整地址才算数：写回她的位置，并让那条演化行带上位置（空间档案据此学到访） |
| 本局还没创建角色 | 先暂存，建角色时作为初始位置写入，用后清空 |
| 字段为空 / 解析失败 | 位置不变（**默认**，绝大多数结局） |

传送只有「结束章节」这一个入口：旧版 `ending` 触发器的动作已经退场（运行时跳过，见 [script.md](script.md) §3.2），所以触发器里没有 `exit_address` 这条路径，校验器也只查章节字段。**允许跨维度**，不加「必须与入口同址」的限制。

进门仍是「门是门」，不改位置：角色有地址时只按入口地址算距离做准入判定，判定通过后位置不动。

## 7. 内部实现

- **子进程里没有地标仓库，也没有风格注册表**：副本会话跑在独立子进程，地标对象上的 `address` 只是相对后缀，私有名却藏在完整地址里。所以地址必须在父进程解析好再进载荷——`merged_landmarks` 换成「每条带完整地址」的纯数据（`address_mode="exact"`），经载荷序列化 / 还原过去（`dungeon/window/launch_payload.py`）。
- **解析复用主世界那一套**：`services/exploration/address_plan.py::landmarks_for_export` 做组合，不另写一份规则。缺省 `portable` 的常见地标会按风格注册地址升级，私有名才跟着进完整地址；显式声明过 `address_mode` / `address` 的按原样解析。
- **解析失败的地标照样进载荷**（名字、尺寸不变，只标成 `portable`、不参与私有名过滤）——不能因为一条坏地址让整个地标消失。

## 8. 拓展用法

- **虚构地点也能有参照物**：`place` 写个名字、`address` 留空、`scene_landmarks` 就地写尺寸，这一章就有地点行和换算句了。地址留空只影响「取景」与传送，不影响内联地标——架空世界不必先申领地址。
- **借别的世界的常见参照物**：私有名过滤只看「完整地址的约束段是否同名」，不校验这一章属于哪个世界。填上另一个世界的私有名，就能把这章摆到那个世界的地理背景里（穿越、回忆、他乡），代价是那一世界的常见地标会整批进池。

## 9. 校验

| 问题 | 级别 |
|---|---|
| 章节独特地标 `size` 非数 / ≤ 0 | error |
| `dimension` 非法 | error |
| 本章内重名 | error |
| 名字含换行或超过 40 字（直进提示词） | error |
| 章节 `address` / `exit_address` 无法解析 | error |
| `common_private_name` 含非法字符 / 超 64 字 | warning（常见地标会匹配不到） |
| 章节 `scene_landmarks` 不是数组 | warning（按空清单处理） |
| `horizontal_type` 取值非法 | warning（回落默认） |
| 本章只有一种 `dimension` | warning |
| 章节独特地标超过 5 条 | warning（建议 ≤5） |
| 方案级 `scene_landmarks` / 章节 `landmarks`（已退役字段） | warning（提示迁移） |
| 章节 `address` 与入口地址跨维度 / 跨一级地域 | warning（只提示，不拦截） |

编辑器在存盘前拦一遍写坏的条目（名称缺失 / 重复 / 尺寸非正数当场弹窗）——运行期遇到坏条目只会静默跳过，不如当场说清。

## 10. 作者须知

<details>
<summary>验收口径（改到地点、参照物或传送后对照）</summary>

1. **空配置**：没配独特地标、也没填私有名 → 空池，不产生换算句，**不回落全量**；
2. **私有名过滤**：完整地址私有名一致的常见地标进池（含导出侧按风格注册地址升级的缺省 `portable` 条目）；不一致 / 没填私有名 / 独特地标不进；
3. **并集与同名**：两者都配时取并集，同名以独特地标为准；
4. **坏条目**：写坏的一条被跳过（校验 error），不拖垮其余条目；
5. **影响不到推进**：改清单 / 改私有名不改变可达章节与结局集合；
6. **会话访问器与提示词**：候选池按章节缓存、切章失效；换算句取自本章池子；空池不产生换算句；
7. **载荷里的完整地址**：父进程解析 → JSON 往返 → 子进程仍能按私有名过滤；
8. **展示**：`place` / 紧凑地址 / 空三种形态，地点行紧跟章节行，虚构章节不出现；
9. **结局传送**：写回位置并留一条带位置的演化行；坏地址不动；未建角色时暂存且只消费一次；
10. **同时在场触发**：她的名字与章节独特地标的名字同段或分处相邻两段 → 下一轮提示出现该地标的对比；只有地标名没有她 / 相隔超过两段 / 上一轮刚提示过 → 不出现；部位途径不受影响。

候选池随玩家世界而变是可接受的（第 5 条）——它只影响措辞，不影响这局会走到哪里。

</details>
