# 世界包：一次换掉整套世界

> **这一篇回答什么问题**：资源中心里那张「世界包」卡片是什么、拿到别人的包怎么装进来、
> 启用之后哪些东西会变、停用和删除之后素材都去了哪。想自己做包、写清单，看
> [author.md](author.md)。
>
> - **刚拿到一个包**：§2 装进来 → §3 启用 → §4 列表变短是不是出了问题。
> - **想删掉一个包**：§5，删除是这里唯一不可逆的动作。
> - **想自己做包**：[author.md](author.md)（打包向导、包内布局、`world.json` 字段）。

## 1. 世界包是什么

世界包是**一整套可搬迁的世界**：地标风格、描述风格、取材表、副本方案、行为包、挑战包、
话题表、小游戏，挑其中若干种打成一个 zip。它的用处是一次切换整批素材，不必逐个去资源
中心里调。

在资源中心「世界包」页签里，一个包就是一张卡片：启用中的排在最前面、挂着「启用中」，
卡片图标取包目录里的 `icon.png`（没有就用内置占位图）。

三条会反复用到的规则：

- **同一时间只有一个启用的包**。点另一个包会先停掉当前的，再启用新的，不会串；
- **包在磁盘上就是一个目录** `data/worlds/<world_id>/`，分享出去时压成
  `<world_id>.world.zip`；
- **启用期间只接管它声明过的类型**。没声明的类型、以及你自己那些跟它不冲突的素材，
  照旧可用。

## 2. 装进来：目前只能手动放

导入和导出都只有服务层实现，资源中心还没有对应按钮。别人给你一个 `<id>.world.zip` 时，
手动放进去一样能用：

1. 解压，得到包根目录（`world.json` 就在这一层）；
2. 把整个目录放进 `data/worlds/`，目录名必须和包里的 `world_id` 一致；
3. 回资源中心刷新，「世界包」页签里就出现这张卡片。

放进去不等于启用——**启用之前它不影响任何东西**。

> 手动放这条路绕过了导入时的路径与成员检查，只对信得过的来源用。包里的行为包是
> Python 代码，启用时会在你的电脑上执行；程序不会自行联网下载或安装世界包。

## 3. 启用、切换与停用

点卡片就是启用。启用期间，各类素材的来源变成这样：

| 你看到的 | 启用期间 |
|---|---|
| 地标风格 / 描述风格 | 列表变成「包里全列 + 仍然可用的你自己的风格」（包没声明地址维度时就只剩包内的，见 §4） |
| 取材表 | 整组换成包里的，选择框被锁 |
| 副本方案 | 包里带的方案出现在列表，内置默认方案照旧 |
| 挑战包 / 小游戏 | 优先用包里的 |
| 世界设定、种子、取材表名 | 被包锁住（设置页上这几项变灰） |

**停用**之后，你自己的设置整体读回来，列表恢复原样；包仍然留在磁盘上，随时能再启用。
**切换**就是点另一个包：程序先停当前的，再启新的。

程序每次启动都会自动恢复上次启用的包。包坏了（清单被改坏、目录被删）只打印一条警告并把
启用状态摘掉，不影响启动——这时你会发现列表里它不再挂着「启用中」。

> 启用之后修改包里的 `world.json` 不会即时生效：清单只在启用、列表刷新和启动时读，
> 改完要重新启用一次。

## 4. 启用之后，我自己的素材还在不在

这是最容易误会的一处。答案是：**都在，只是暂时读不到**。

- 和包里**同名**的风格会被包里的遮住；停用后原样回来，你的文件既没被删也没被改。
- 包没有声明地址维度时，地标 / 描述风格列表**只剩包内的**——列表变短是正常现象，不是
  素材丢了。
- 不同名、也没和包抢同一个地址维度的风格，仍然可选可用。

一句话：启用只改「现在读哪一份」，不动你的文件。

## 5. 删除与解散

删除按钮只长在**启用中**的卡片上；其它卡片点一下是启用。所以想删一个没启用的包，得先
点它启用。

点「删除」会问一句：要不要把包内资源解散到自由资源？

| 选择 | 结果 |
|---|---|
| 解散（是） | 先停用，再把包里各类素材搬回你自己的资源目录，之后照常可选可用 |
| 直接删（否） | 停用，然后只删包目录——包里的素材跟着一起没了 |
| 取消 | 什么都不做 |

解散时重名不会覆盖：目标已被占用就自动改名（`<原名>_<world_id>_<版本>`，还撞就继续
`_2`、`_3`），你原来那份的信封优先。

## 6. 官方资源

发行版**不自带世界包**——首次启动 `data/worlds/` 是空的，列表里那句「暂无世界包」就是
这个意思。官方素材都以普通资源的形式给出来（内置清单见
[../resources.md](../resources.md) §14）。想立刻体验一次世界包，最省事的做法是用
「＋ 新建」把内置素材打一个包。
